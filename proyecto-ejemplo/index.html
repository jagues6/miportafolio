🎨 Proyecto Ejemplo

📅 Creado: Marzo 2026

📝 Descripción

Este es un proyecto de ejemplo que demuestra cómo crear una página individual dentro de una carpeta separada. Esta estructura permite organizar múltiples proyectos de manera ordenada.

🎯 Objetivos

  • Aprender a estructurar proyectos en carpetas separadas
  • Crear enlaces relativos entre páginas
  • Entender cómo subir múltiples proyectos a GitHub Pages

🛠️ Tecnologías Utilizadas

HTML5 CSS3 Diseño Responsivo

📚 Lo que aprendí

En este proyecto practiqué:

  • Estructura semántica de HTML5
  • Uso de gradientes CSS
  • Creación de tarjetas con sombras
  • Enlaces relativos (../index.html)
